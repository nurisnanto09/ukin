Apa Itu Pseudocode?

Berasal dari kata pseudo (semu/tiruan) dan code (kode program)

Pseudocode (Kode Semu) adalah cara penulisan algoritma menggunakan bahasa manusia terstruktur yang menyerupai bahasa pemrograman, namun tidak terikat oleh aturan sintaksis bahasa komputer manapun (seperti titik koma, kurung kurawal, atau tanda kurung kaku).

🎯 Mengapa Kita Menggunakan Pseudocode?

  • Fokus pada Logika Solusi: Pemrogram dapat merancang algoritma tanpa terdistraksi kesalahan penulisan (*syntax error*).
  • Universal & Agnostik: Algoritma pseudocode yang sama bisa diubah ke bahasa Python, C++, Java, maupun JavaScript dengan mudah.
  • Mudah Dipahami Manusia: Menggunakan kata-kata intuitif seperti INPUT, OUTPUT, IF-THEN-ELSE, dan tanda panah <-.
⭐

3 Aturan Emas Notasi

1. HURUF KAPITAL:
Kata kunci ditulis huruf besar: PROGRAM, DEKLARASI, INPUT, IF.
2. Operator Panah (<-):
Mengisi variabel: nilai <- 80 (bukan tanda sama dengan =).
3. Indentasi Menjorok:
Beri spasi masuk untuk baris di dalam blok IF...THEN.

🔄 Perbandingan: Bahasa Sehari-hari vs Pseudocode vs Python

1. Bahasa Alami Deskriptif

"Minta pengguna memasukkan nilai ujian. Jika nilai tersebut 75 atau lebih, katakan siswa lulus. Namun jika di bawah 75, katakan siswa remedial."

Kelemahan: Terlalu panjang, ambigu.
2. Notasi Pseudocode Standar Kita 
INPUT(nilai)
IF nilai >= 75 THEN
    OUTPUT("Lulus")
ELSE
    OUTPUT("Remedial")
ENDIF
Kelebihan: Rapi, terstruktur, siap dikoding.
3. Bahasa Pemrograman (Python) Eksekusi Mesin 
nilai = int(input())
if nilai >= 75:
    print("Lulus")
else:
    print("Remedial")
Harus patuh aturan sintaks bahasa.

Bagian 1: Judul (Header)

Identitas & Spesifikasi Algoritma

Bagian Judul berfungsi memberikan nama pengenal unik untuk algoritma serta menjelaskan secara ringkas apa tujuan program tersebut dibuat.

Format Standar:
PROGRAM Nama_Algoritma
{ Penjelasan ringkas apa yang dikerjakan program }
Aturan Penamaan Algoritma:
  • Tidak boleh ada spasi: Gunakan garis bawah (_) atau huruf kapital camelCase.
  • Harus diawali huruf alfabet: Contoh: Hitung_Luas (Benar), 123Hitung (Salah).
  • Tidak menggunakan karakter khusus: Dilarang memakai simbol ! @ # $ % ^ & * ( ) - +.
  • Bermakna & Singkat: Menggambarkan tugas algoritma secara spesifik.

Bagian 2: Deklarasi (Kamus)

Pemesanan Memori & Tipe Data

Sebelum komputer dapat menyimpan atau mengolah data, komputer harus memesan wadah (alokasi memori RAM) terlebih dahulu. Bagian Deklarasi adalah tempat mengenalkan semua variabel dan konstanta yang akan dipakai.

4 Tipe Data Dasar:
integer
Bilangan bulat
10, -5, 100
real / float
Bilangan desimal
3.14, 85.5
string
Teks / Karakter
"Budi", "Lulus"
boolean
Logika benar/salah
true, false

Bagian 3: Isi (Deskripsi)

Jantung Aksi & Alur Eksekusi

Bagian Isi adalah jantung dari seluruh algoritma. Di sinilah urutan perintah komputasi dijalankan secara sistematis baris demi baris dari atas ke bawah.

📥 1. INPUT / READ (Membaca Masukan)

Menerima data masukan dari pengguna dan menyimpannya ke variabel.

INPUT(panjang, lebar)
🔄 2. ASSIGNMENT (<-) (Pemberian Nilai)

Menghitung ekspresi di kanan panah, lalu menyimpannya ke variabel kiri.

luas <- panjang * lebar
🔀 3. PERCABANGAN (IF - THEN - ELSE)

Menentukan percabangan aksi berdasarkan kondisi benar (true) atau salah (false).

IF nilai >= 75 THEN ... ELSE ... ENDIF
📤 4. OUTPUT / WRITE (Menampilkan Keluaran)

Mencetak hasil perhitungan ke layar pengguna.

OUTPUT("Luas = ", luas)
