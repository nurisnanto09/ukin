1 Aktivitas 1: Mengenal Kata Kunci Pseudocode & Konsep Variabel
C1 - C2 Memahami

Pseudocode (Kode Semu) adalah cara penulisan algoritma menyerupai bahasa pemrograman komputer menggunakan teks terstruktur. Data disimpan dalam Variabel (wadah di memori komputer yang isinya dinamis: berat_kg, poin_admin, total_poin), lalu diproses lewat: INPUT (Masukan), PROSES (Perhitungan & IF-ELSE), dan OUTPUT (Keluaran).

Kata Kunci Contoh di Patbhe Green Fungsi / Kegunaan (Tuliskan Analisismu)
VARIABEL / DEKLARASI total_poin : real
INPUT / READ INPUT berat_kg
OUTPUT / PRINT PRINT "Total Poin: ", total_poin
<- (Assignment) total_poin <- berat_kg * poin_admin
IF ... THEN IF total_poin >= 100 THEN
ELSE ELSE PRINT "Ayo Tingkatkan"
END IF END IF
📦
Konsep Variabel: Wadah penyimpanan data di memori komputer yang diberi nama pengenal (contoh: berat_kg, total_poin, poin_admin) di mana nilainya dapat berubah-ubah (dinamis) sepanjang program berjalan.

Studi Kasus Kontekstual: Sistem Pencatatan Setoran Sampah "Patbhe Green"

Bank Sampah Sekolah "Patbhe Green" mengembangkan program di posko penimbangan untuk mencatat setoran sampah botol plastik dari tiap kelas. Tarif poin per kilogram (poin_admin) bersifat dinamis (dapat diubah saat ada pekan lingkungan). Total poin diperoleh dari rumus perkalian: total_poin = berat_kg * poin_admin.

patbhe_green_sekuensial.pseudo SEKUENSIAL
1.Program Hitung_Poin_Patbhe_Green
2.{ Menghitung poin perolehan kelas }
3.Deklarasi:
4.nama_kelas : string
5.berat_kg, poin_admin, total_poin : real
6.Algoritma:
7.INPUT nama_kelas
8.INPUT berat_kg
9.INPUT poin_admin
10.total_poin <- berat_kg * poin_admin
11.OUTPUT "=== BUKTI SETORAN ==="
12.OUTPUT "Kelas : ", nama_kelas
13.OUTPUT "Total Poin : ", total_poin
14.END

Studi Kasus: Otomatisasi Sistem Perankingan Kelas Patbhe Green

Sebagai bagian dari komitmen Sekolah Adiwiyata Mandiri di SMA Negeri 4 Yogyakarta, panitia program "Patbhe Green" menyelenggarakan kompetisi kebersihan dan pengumpulan sampah daur ulang antarkelas setiap bulannya. Di setiap akhir periode, pihak sekolah mengumumkan pergerakan peringkat kelas untuk memberikan apresiasi bagi kelas yang paling konsisten menjaga lingkungan.

Namun, selama ini panitia Adiwiyata masih membandingkan perolehan nilai kelas satu per satu secara manual. Proses manual ini memakan waktu lama, rawan salah catat, dan sering membuat pengumuman peringkat kelas terlambat diumumkan saat apel sekolah.

💡 Tantangan Komputasional Kelompokmu:
Pihak sekolah meminta kelompok kalian merancang logika program pseudocode percabangan (IF-ELSE) yang dapat mengambil keputusan otomatis: Sistem akan menerima masukan berupa nilai poin terkini (nilai) dan nilai poin periode sebelumnya (nilai_sebelumnya). Jika nilai sekarang lebih besar dari nilai sebelumnya, maka peringkat kelas naik (lebih tinggi). Sebaliknya jika tidak, peringkat kelas tidak naik.

📈 Kondisi 1: Nilai Lebih Besar dari Nilai Sebelumnya

Jika nilai > nilai_sebelumnya, cetak: "Peringkat Lebih Tinggi 🏆"

📉 Kondisi 2: Tidak Lebih Besar (ELSE / Tetap atau Turun)

Jika tidak (nilai ≤ nilai sebelumnya), cetak: "Peringkat Tetap / Turun ⬇️"
