1 Aktivitas 1: Mengenal Kata Kunci Pseudocode & Konsep Variabel
C1 - C2 Memahami

Pseudocode (Kode Semu) adalah cara penulisan algoritma menyerupai bahasa pemrograman komputer menggunakan teks terstruktur. Data disimpan dalam Variabel (wadah di memori komputer yang isinya dinamis: berat_kg, poin_admin, total_poin), lalu diproses lewat: INPUT (Masukan), PROSES (Perhitungan & IF-ELSE), dan OUTPUT (Keluaran).

Kata Kunci Contoh di Patbhe Green Fungsi / Kegunaan (Tuliskan Analisismu)
VARIABEL / DEKLARASI total_poin : real
INPUT / READ INPUT berat_kg
OUTPUT / PRINT PRINT "Total Poin: ", total_poin
<- (Assignment) total_poin <- berat_kg * poin_admin
IF ... THEN IF total_poin >= 100 THEN
ELSE ELSE PRINT "Ayo Tingkatkan"
END IF END IF
📦
Konsep Variabel: Wadah penyimpanan data di memori komputer yang diberi nama pengenal (contoh: berat_kg, total_poin, poin_admin) di mana nilainya dapat berubah-ubah (dinamis) sepanjang program berjalan.

Studi Kasus Kontekstual: Pengumpulan Sampah Daur Ulang Sekolah

Sekolah mengadakan kegiatan pengumpulan sampah daur ulang. Setiap kelas dapat menyetorkan botol plastik dan kardus ke tempat penimbangan. Petugas mencatat jenis dan berat sampah, kemudian memasukkan tarif poin sesuai ketentuan sekolah. Botol plastik memperoleh 10 poin/kg, sedangkan kardus memperoleh 20 poin/kg. Program menghitung total poin dari setiap setoran dan menampilkan hasilnya.

patbhe_green_sekuensial.pseudo SEKUENSIAL
1.Program Hitung_Poin_Sampah_Daur_Ulang
2.{ Menghitung poin perolehan kelas }
3.Deklarasi:
4.nama_kelas, jenis_sampah : string
5.berat_kg, tarif_poin, total_poin : real
6.Algoritma:
7.INPUT nama_kelas
8.INPUT jenis_sampah
9.INPUT berat_kg
10.INPUT tarif_poin
11.total_poin <- berat_kg * tarif_poin
12.OUTPUT "=== BUKTI SETORAN ==="
13.OUTPUT "Kelas : ", nama_kelas
14.OUTPUT "Jenis Sampah : ", jenis_sampah
15.OUTPUT "Total Poin : ", total_poin
16.END

Studi Kasus: Otomatisasi Penentuan Tarif & Perhitungan Poin Sampah Daur Ulang

Sekolah mengadakan kegiatan pengumpulan sampah daur ulang. Setiap kelas dapat menyetorkan botol plastik dan kardus ke tempat penimbangan. Petugas mencatat jenis dan berat sampah, kemudian memasukkan tarif poin sesuai ketentuan sekolah. Botol plastik memperoleh 10 poin/kg, sedangkan kardus memperoleh 20 poin/kg. Program menghitung total poin dari setiap setoran dan menampilkan hasilnya.

⚠️ Analisis Masalah & Risiko Sistem Manual:

Pada program sekuensial di Aktivitas 2, petugas penimbangan masih harus memasukkan tarif_poin secara manual. Hal ini berisiko tinggi terjadi kesalahan input (human error)—misalnya petugas salah memasukkan tarif botol plastik dengan tarif kardus sehingga perolehan poin kelas menjadi tidak adil dan tidak akurat.

💡 Tantangan Komputasional Kelompokmu:
Untuk mengatasi risiko salah input tarif tersebut, rancanglah logika program pseudocode percabangan (IF-ELSE) yang dapat mengotomatisasi penentuan tarif dan perhitungan total poin secara tepat! Petugas hanya perlu memasukkan nama kelas, jenis sampah ("botol plastik" atau "kardus"), dan berat sampah (kg). Komputer akan otomatis memeriksa jenis sampah, mengunci tarif yang sesuai (10 atau 20), dan menghitung total poin tanpa perlu input tarif manual lagi.
