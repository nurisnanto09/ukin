Kuasai Notasi Kode Semu, Logika IF-ELSE & Penelusuran Variabel

Pseudocode adalah jembatan antara logika berpikir manusia dan bahasa pemrograman komputer. Di materi ini, kamu akan mempelajari deklarasi variabel, assignment panah (<-), percabangan kondisi, hingga simulasi penelusuran baris per baris.

📥 INPUT & OUTPUT 🔄 VARIABEL & PANAH (<-) 🔀 IF - THEN - ELSE 🔁 PERULANGAN (LOOP)
📖 Buka LKPD Murid ↗ Nomor Absen: #-
pseudocode_sample.algo FASE E
1ALGORITMA HitungKelulusan
2DEKLARASI nilai, kkm : INTEGER
3INPUT(nilai)
4kkm <- 75
5IF (nilai >= kkm) THEN
6OUTPUT("TUNTAS / PENGAYAAN")
7ELSE
8OUTPUT("REMIDI BELAJAR")
9ENDIF
▶ Console: nilai = 85 → "TUNTAS / PENGAYAAN"
