Sinkronisasi Spreadsheet

Endpoint Google Apps Script (GAS)

Otomatisasi daftar absen murid dari spreadsheet ke portal.

Daftar lokal aktif (Absen 1 - 20)
Kode Apps Script (Code.gs): 
function doGet() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  var result = [];
  for (var i = 1; i < data.length; i++) {
    result.push({ absen: data[i][0], nama: data[i][1], kelas: data[i][2], nis: data[i][3] });
  }
  return ContentService.createTextOutput(JSON.stringify(result)).setMimeType(ContentService.MimeType.JSON);
}
